## Data Analytics Project — Customer Purchase Analysis

This project analyzes customer purchase behavior using Python, MySQL, and Power BI. The goal is to clean and understand the data, identify meaningful business insights through SQL analysis, and present the findings through an interactive Power BI dashboard and a final presentation.

## 📊 Project Overview

This project presents an end-to-end **Customer Shopping Behavior Analysis** workflow, transforming raw customer transaction data into actionable business insights.

The project follows a structured analytics pipeline:

### 🔹 Python — Data Preparation & EDA
- Imported and explored the raw dataset using Pandas.
- Performed data quality checks and identified missing or inconsistent values.
- Cleaned and prepared the dataset for further analysis.
- Conducted Exploratory Data Analysis (EDA) to understand customer and purchasing patterns.

### 🔹 MySQL — Business Analysis
- Loaded the cleaned dataset into MySQL.
- Developed SQL queries to answer key business questions.
- Analyzed customer spending, product performance, discounts, subscriptions, loyalty, and purchasing behavior.
- Applied SQL concepts including aggregations, subqueries, CTEs, CASE statements, and window functions.

### 🔹 Power BI — Visualization & Dashboard
- Connected the analyzed data to Power BI.
- Designed an interactive dashboard with KPIs and business-focused visualizations.
- Added filters and slicers to enable interactive analysis.
- Presented customer, product, revenue, and purchasing insights in a user-friendly format.

### 🔹 Reporting & Presentation
- Documented the complete analytical process and major findings in a project report.
- Created a professional presentation using **Gamma AI** to communicate key insights, recommendations, and business outcomes.
